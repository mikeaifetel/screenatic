手机、电脑投屏到电视，免费。

Screenatic 让你的 Google TV 或 Fire TV 变成投屏接收器：iPhone、iPad、Mac 屏幕镜像，手机投视频和音乐， Windows 投照片和视频，不用买额外的硬件。

iPhone · iPad · Mac

控制中心的"屏幕镜像"，或视频、音乐 App 里的 AirPlay 按钮，带声音。

安卓 · Windows

在支持 DLNA 的 App 里"投屏"视频、音乐、照片，或使用 Windows 的"投射到设备"。

为电视设计

支持 Google TV / Android TV 和 Fire TV（Fire OS），硬件解码，遥控器操作友好。

使用方法

  1. 在电视上安装并打开 Screenatic。
  2. 确保手机或电脑和电视连接同一个 Wi-Fi。
  3. iPhone / iPad / Mac：控制中心 → 屏幕镜像，或在视频、音乐 App 里点 AirPlay。
  4. 安卓 / Windows：在视频、音乐、相册 App 里点"投屏"（DLNA），或在 Windows 里右键视频 → 投射到设备。
  5. 选择你的电视（"Screenatic TV"）。

# ja-JP

## Title (29/30)

Screenatic: スマホ・PCをテレビにミラーリング

## Short description (57/80)

テレビに無料でミラーリング。iPhone・Mac は AirPlay、Android・PC は DLNA に対応。

## Full description (801/4000)

Google TV や Fire TV を画面ミラーリングのレシーバーに。追加の機器もアカウントも不要、無料で使えます。

できること
• iPhone・iPad・Mac の画面を音声付きでミラーリング（コントロールセンター → 画面ミラーリング）
• YouTube や Safari などのアプリから AirPlay ボタンで動画をテレビで再生
• Apple Music や Spotify などの音楽を再生し、アートワークと曲情報をテレビに表示
• DLNA 対応の Android アプリから動画・音楽・写真をキャスト。Windows の「デバイス キャスト」にも対応

使い方
1. テレビで Screenatic を開きます。
2. スマホやパソコンをテレビと同じ Wi-Fi に接続します。
3. iPhone / iPad / Mac：コントロールセンター → 画面ミラーリング、または動画・音楽アプリで AirPlay をタップ。
   Android / Windows：動画・音楽・写真アプリで「キャスト」（DLNA）をタップ、または Windows で動画を右クリック → デバイス キャスト。
4. 「Screenatic TV」を選択します。

ポイント
• ミラーリング中にリモコンの OK ボタンで「フィット」と「フィル」を切り替えられます。
• ハードウェアデコードでなめらかに表示。
• ログイン不要、トラッキングなし。キャストした内容はご自宅のネットワーク内にとどまります。

# zh-CN

## Title (20/30)

Screenatic：手机电脑投屏到电视

## Short description (49/80)

免费电视投屏：iPhone、Mac 用 AirPlay，安卓手机和 Windows 用 DLNA。

## Full description (652/4000)

让你的 Google TV 或 Fire TV 变成投屏接收器：不用额外硬件，不用注册账号，免费使用。

功能
• iPhone、iPad、Mac 屏幕镜像，带声音（控制中心 → 屏幕镜像）
• 在 YouTube、Safari 等 App 里点 AirPlay，把视频投到电视上播放
• 投送 Apple Music、Spotify 等音乐，电视上显示封面和歌曲信息
• 安卓手机在支持 DLNA 的 App 里投视频、音乐、照片；Windows 可用"投射到设备"

使用方法
1. 在电视上打开 Screenatic。
2. 手机或电脑连接与电视相同的 Wi-Fi。
3. iPhone / iPad / Mac：控制中心 → 屏幕镜像，或在视频、音乐 App 里点 AirPlay。
   安卓 / Windows：在视频、音乐、相册 App 里点"投屏"（DLNA），或在 Windows 里右键视频 → 投射到设备。
4. 选择"Screenatic TV"。

小贴士
• 镜像时按遥控器的 OK 键，可在"适应屏幕"和"铺满屏幕"之间切换。
• 硬件解码，镜像画面流畅。
• 无需登录，不做追踪，投屏内容只在你的局域网内传输。

## Title (20/30)

Screenatic：手機電腦投放到電視

## Short description (57/80)

免費電視投放：iPhone、Mac 使用 AirPlay，Android 手機和 Windows 使用 DLNA。

## Full description (674/4000)

讓你的 Google TV 或 Fire TV 變成投放接收器：不需額外硬體、不需註冊帳號，免費使用。

功能
• iPhone、iPad、Mac 螢幕鏡像輸出，含聲音（控制中心 → 螢幕鏡像輸出）
• 在 YouTube、Safari 等 App 點選 AirPlay，把影片投放到電視播放
• 投放 Apple Music、Spotify 等音樂，電視上顯示封面和歌曲資訊
• Android 手機可在支援 DLNA 的 App 投放影片、音樂、相片；Windows 可使用「投放到裝置」

使用方式
1. 在電視上開啟 Screenatic。
2. 手機或電腦連接與電視相同的 Wi-Fi。
3. iPhone / iPad / Mac：控制中心 → 螢幕鏡像輸出，或在影片、音樂 App 點選 AirPlay。
   Android / Windows：在影片、音樂、相簿 App 點選「投放」（DLNA），或在 Windows 對影片按右鍵 → 投放到裝置。
4. 選擇「Screenatic TV」。

小提醒
• 鏡像時按遙控器的 OK 鍵，可在「適應畫面」和「填滿畫面」之間切換。
• 硬體解碼，鏡像畫面流暢。
• 不需登入，投放內容只在你的區域網路內傳輸。

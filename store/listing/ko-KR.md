## Title (25/30)

Screenatic: 휴대폰·PC TV 미러링

## Short description (56/80)

TV로 무료 화면 미러링: iPhone·Mac은 AirPlay, Android·PC는 DLNA 지원.

## Full description (825/4000)

Google TV나 Fire TV를 화면 미러링 수신기로 바꿔 보세요. 추가 장비나 계정 없이 무료로 사용할 수 있습니다.

주요 기능
• iPhone, iPad, Mac 화면을 소리와 함께 미러링 (제어 센터 → 화면 미러링)
• YouTube, Safari 등 앱에서 AirPlay 버튼으로 동영상을 TV에서 재생
• Apple Music, Spotify 등의 음악 재생, TV에 앨범 아트와 곡 정보 표시
• DLNA를 지원하는 Android 앱에서 동영상·음악·사진 캐스트, Windows의 '디바이스로 캐스트' 지원

사용 방법
1. TV에서 Screenatic을 엽니다.
2. 휴대폰이나 컴퓨터를 TV와 같은 Wi-Fi에 연결합니다.
3. iPhone / iPad / Mac: 제어 센터 → 화면 미러링, 또는 동영상·음악 앱에서 AirPlay를 탭합니다.
   Android / Windows: 동영상·음악·사진 앱에서 '캐스트'(DLNA)를 탭하거나, Windows에서 동영상을 마우스 오른쪽 버튼으로 클릭 → 디바이스로 캐스트.
4. 'Screenatic TV'를 선택합니다.

알아 두세요
• 미러링 중 리모컨의 OK 버튼으로 '맞춤'과 '채우기'를 전환할 수 있습니다.
• 하드웨어 디코딩으로 부드럽게 표시됩니다.
• 로그인 없음, 추적 없음. 캐스트한 콘텐츠는 내 네트워크 안에만 머뭅니다.
